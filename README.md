# 🚀 Neon Space Shooter

A cyberpunk-style space shooter game built with pure HTML5 Canvas.

## 🎮 Play Now
[Play the game](https://YOUR-USERNAME.github.io/neon-space-shooter/)

## ✨ Features
- 🎯 Touch & mouse controls
- 🌟 Neon cyberpunk graphics
- 💥 Particle explosion effects
- 🏆 High score system (saved locally)
- 📱 Mobile-friendly
- 🚀 Share your score on social media

## 🎯 How to Play
- **Move**: Touch and drag (mobile) or move mouse (desktop)
- **Shoot**: Tap (mobile) or click (desktop)
- **Goal**: Destroy enemies and get the highest score!

## 🛠️ Built With
- HTML5 Canvas
- Pure JavaScript (no frameworks)
- CSS3 animations
