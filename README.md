## ✨ Features

- 🎯 **Touch & Mouse Controls** - Play on mobile or desktop
-  **Neon Cyberpunk Graphics** - Beautiful glowing effects
- 💥 **Particle Explosion System** - Satisfying visual feedback
-  **High Score System** - Your best score is saved locally
- 📱 **Fully Responsive** - Works on all screen sizes
- 🚀 **Share Feature** - Share your score on social media
- 🎨 **Smooth Animations** - 60 FPS gameplay

---

## 🎯 How to Play

### Controls:
- **Move**: Touch and drag (mobile) or move mouse (desktop)
- **Shoot**: Tap (mobile) or click (desktop)

### Goal:
Destroy the falling enemies and get the highest score possible! Don't let them hit you!

---

## 🛠️ Built With

- **HTML5 Canvas** - Rendering engine
- **Pure JavaScript** - No frameworks, vanilla JS
- **CSS3** - Styling and animations
- **GitHub Pages** - Hosting

## 📦 Installation

Want to run it locally?

```bash
# Clone the repository
git clone https://github.com/sepantartd/neon-space-shooter.git

# Navigate to the folder
cd neon-space-shooter

# Open index.html in your browser
# That's it! No build process needed
```

## 🎮 Gameplay Tips

1. **Stay Mobile** - Keep moving to avoid enemies
2. **Rapid Fire** - Tap quickly to shoot faster
3. **Edge Strategy** - Stay near edges for better angles
4. **Focus** - Destroy enemies before they reach you
